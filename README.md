🧠 AI-Driven Development & Best Practices (The AI Module)
A core pillar of this course is teaching students how to work smart with AI (using tools like Claude, ChatGPT, etc.) rather than just copy-pasting code. We focus heavily on engineering productivity and architectural integrity.

What TO Do with AI (Best Practices)
Boilerplate & Setup: Generating initial project structures, configuration files, and repetitive schema definitions.
Refactoring & Optimization: Asking the AI to analyze code smells, suggest design patterns, or optimize Pandas vectorized operations over slow loops.
Debugging & Log Analysis: Pasting stack traces, error logs, or memory leak reports to quickly identify root causes.
Test Generation: Writing unit tests (pytest) and edge-case scenarios based on existing business logic.
Custom Skills & Prompts: Creating repository-level instructions (CLAUDE.md or system prompts) to enforce team coding standards and project context.
What NOT To Do with AI (Pitfalls to Avoid)
Blind Copy-Pasting: Never integrate code you don't fully understand line-by-line.
Security & Secrets: Never paste production database credentials, API keys, or sensitive business logic into public LLMs.
Architecture Without Planning: Relying on AI to "design the whole system from scratch" without a clear domain model usually leads to spaghetti code.
Ignoring Context Limits: Dumping massive legacy codebases into a prompt instead of isolating the specific component you want to fix.

⚙️ Getting Started
Clone the repository:

Bash
git clone [https://github.com/ronelkayam/advanced-python-backend-ai.git](https://github.com/ronelkayam/advanced-python-backend-ai.git)
cd advanced-python-backend-ai
Create and activate a virtual environment:

Bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
Install dependencies:

Bash
pip install -r requirements.txt
